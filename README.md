# The Last Ember

A dark fantasy adventure map for Minecraft Java Edition 26.3, built for 2–3 players in co-op.

No mods, no plugins, no command blocks. Everything runs on a vanilla datapack and resource pack.

## Status

Early development.

## Structure

- `datapack/` — game logic, worldgen tweaks, loot, mobs
- `resourcepack/` — textures, models, sounds, music
- `tools/` — scripts: seed search, map renders, tests
- `docs/` — reports and reference data for 26.3
- `server/` — local test server (not tracked)

## Requirements

- Minecraft Java Edition 26.3
- All players must use the resource pack
