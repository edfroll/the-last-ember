# T-021: границы регионов, ворота глав, шорткаты. Генератор: python3 tools/gen_gates.py [доп_файл]  (затем python3 tools/gen_zones.py)
# Поля через пробелы, # — комментарий.
#
# border <id> x|z <ось> <от> <до> [gap=<от>..<до> ...] [strip=40]
#   граница по оси x = <ось> (тогда <от>..<до> — по z) или z = <ось> (тогда по x). Барьер (barrier) — плоскость толщиной 1 блок
#   по оси на всю высоту мира, кроме проёмов gap (под ворота); ставит офлайн tools/borders.sh apply. Полоса приключения ±strip
#   (зона с флагом border в zones/gates.gen.txt). Над y 316 датапак не пускает через ось (элитры, жемчуг выше мира).
# gate <id> <регион, который открывает: r2..r6|final> chapter=<N> [at=x,y,z | at=x,~,z] [closed=<шаблон> open=<шаблон>]
#      [text="строка над хотбаром"] [dim=overworld]
#   ворота главы: открываются крючком altar/hook/chapter_<N> (function last_ember:gate/open {id:"<id>"}), ставят #open_<регион>.
#   at — точка события (звук, частицы); с шаблонами — точка place template (угол шаблона). y "~" — по поверхности.
#   Без шаблонов — только флаг, событие и крючок gate/hook/<id>.
# shortcut <регион r1..r6> door=x,y,z yaw=<0|90|180|270> [open=click|near:<r>] [hub=<регион>] [build=1]
#   дверь шортката в регионе (door = нижняя половина двери, yaw — куда смотрит дверь: 0 юг, 90 запад, 180 север, 270 восток).
#   Сторона Приюта (ворота на площади, T-008) есть у всех шести регионов всегда; строка shortcut добавляет сторону региона.
#   build=1 — датапак сам ставит шаблон двери (structure/shortcut/door_<регион>), когда чанк загружен. Без строки shortcut
#   ворота Приюта заперты («Заперто с той стороны»).
