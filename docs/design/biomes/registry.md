# The Last Ember · Реестр биомов

Oct 20, 2026 · Архитектор → Штаб · версия 1.3: Р0–Р3, музыка сведена, Предстенье и Ржавый Разлом

Один документ на все свои биомы карты. По нему билдер собирает биомы датапака и заливает их `fillbiome`. Цвета, уже утверждённые в карточках, перенесены без изменений и помечены «утверждено». Всё остальное — предложения Архитектора.

## Как читать

**Поля записи.**

| Поле | Что значит |
| --- | --- |
| id | Имя в датапаке, пространство `last_ember` |
| Цвета | Небо, туман, вода, туман под водой, трава, листва. Листва перекрашивается только у дуба, тёмного дуба, джунглей, акации и мангра. У ели, берёзы, вишни, бледного дуба и тополя 26.3 цвет свой |
| Дальность тумана | Намерение в блоках: где туман начинается и где закрывает всё. Пусто — ванильная дальность |
| Осадки | Чем станет дождь мира в этом биоме: дождь, снег или ничего. Погода общая на весь мир |
| Атрибуты окружения | Намерение. Что работает на уровне биома, проверит билдер первым шагом задачи |
| Спавн | Предложение Архитектора по угрозам региона. Утверждает Штаб |
| Контур | Прямоугольник, круг или объём, всё по сетке 4 |
| Переход | Ширина полосы, через которую биом сходит в соседний |
| «Угасшая» версия | Какой биом ставится на это место после главы и по какому контуру |

**Порядок заливки.** Сначала основа региона на весь его прямоугольник, потом биомы локаций поверх, потом ванильные биомы локаций (бледный сад). Так каждый следующий биом перекрывает предыдущий, а основа остаётся везде, где ничего другого нет. «Угасшие» версии заливаются в момент события главы поверх того же места.

**Музыка.** В поле указан слот трека. Сами треки — музыка Эдварда в ресурс-паке. Правило Штаба: один фоновый трек на регион, отдельные — только для Приюта, мест-передышек и логов боссов. Слоты:

| Слот | Что это | Биомы |
| --- | --- | --- |
| `refuge` | Приют | `twilight_refuge` |
| `grove` | передышка Р1 | `mushroom_grove` |
| `healing` | передышка Р2 | `healing_vale`, `healing_vale_faded` |
| `r1_vale` | регион Р1 | все остальные биомы Р1, Предстенье, «Предзимье», Ржавый Разлом |
| `r2_ring` | регион Р2 | все остальные биомы Р2 |
| `r3_silence` | регион Р3 | все биомы Р3 |
| `lair_castle` | лог босса Р1: замок | `castle_dream`, `castle_dream_faded` |
| `lair_temple` | лог Р2: остров и храм древнего стража | `mist_isle` |

Бой с боссом на арене — отдельная музыка датапака по триггеру арены, это не биом. Сад Безмолвия — без музыки, ванильная тишина. Ванильные биомы (бледный сад, пещеры) свою музыку не меняют.

## Р3 · Полынья · `polynya`

Служебный биом. В холодном биоме открытая вода под небом сама покрывается льдом, а полыньи на Ледяной реке — ловушки, и они должны оставаться открытыми. Поэтому на каждую полынью — столбик 4×4 (или 8×8) этого биома: цвета и туман те же, что у Тиши, а температура выше 0,15, чтобы вода не замерзала и снег на ней не ложился.

| Поле | Значение |
| --- | --- |
| Все цвета, туман, частицы, звуки, музыка, спавн, атрибуты | как у `white_silence` |
| Осадки | дождь: в снегопад над полыньёй вместо снега капли — заметно только тому, кто смотрит вверх, и это подсказка |

| Переход | нет |

Тот же приём пригодится везде, где в холодном биоме нужна незамерзающая вода: Пост, ров, колодцы.

## Вопросы Штабу по Р3

1. **Нежить не горит.** Предлагаю выключить `monsters_burn` во всей Тиши: небо стальное, солнце не греет, днём так же опасно, как ночью. Это сильно меняет баланс главы — решай.
2. **Сон в Тиши.** Карточка задала намерение: обычная кровать не работает, соломенная работает. Атрибут `straw_bed_rule` в 26.3 есть. Подтверди, что соломенная кровать — та, что у костров, и её можно носить с собой.
