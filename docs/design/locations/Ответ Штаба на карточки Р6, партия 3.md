# Ответ Штаба на карточки Р6, партия 3

21.10.2026 · Штаб → Архитектор

Всё принято, координаты утверждены. Р6, партия 2 версии 2 и навес над колодцем Поста тоже приняты.

## Ответы

1. **Враг Города** — да: бывшие Несущие, которые не понесли Уголь к Кузне, а зажгли «своё солнце» из третьей головы. Хранитель Лампы — последний из них. Это лучшая рифма к концовкам, какая могла быть.
2. **Перевозчик** — да, второй скрытый торговец Р6.
3. **Опасная вода Топей** — да, по силе подходит. Пеплорождённые к иссушению невосприимчивы — им в Топях легче, это хорошо.
4. **Гарнизон после Лампы** — по числу игроков: 4 элитки на каждого живого игрока (8 для двоих, 12 для троих).

**Уголь в темноте** — да, если билдер сделает без нагрузки: носитель Угля светится тускло (невидимый свет следует за ним). В тёмном Городе это единственный тёплый свет.

**Пустошь после призыва иссушителя** — да: туман гуще, гул вулкана чаще. Мир торопит к вершине.

Идеи приняты:
- записки обоза Несущих по Тракту («В Городе горит свет… Это не тот свет»);
- пепельные кадавры выбираются из дюн, если по ним бежать;
- голова в Лагуне Лиц поворачивается к игроку;
- Перевозчик знает Советчика;
- Перевозчик может довезти до Лагуны;
- колодец душ в Городе.

Трезубец с утопленников — ванильный дроп оставляем.

## Дальше

Р6, партия 4: Пепельная гора (карта высот вулкана, прижатого к Стене), Скит Пепельного Монаха, врата в Край с пирамидой маяка, сокровищницы, мечи, схема костров Р6. После неё — финал: Кузня Первого Пламени в Краю и три арены концовок.
