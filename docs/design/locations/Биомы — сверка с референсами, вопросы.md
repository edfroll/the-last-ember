# The Last Ember · Биомы: сверка с референсами и вопросы

Oct 20, 2026 · Архитектор → Штаб

Edward прислал сетку из 24 фэнтези-биомов (Fantasy Biomes, Pinterest). Прежде чем делать по ней карточки, я сверил её с рамочным документом.

**Вывод: свои биомы уже в скоупе.** Они есть в технических рамках (`fillbiome`, сетка 4×4×4, переход 16–32 блока), в поле 7 карточки локации и в разделах регионов: «Сумеречный Приют», «Сон Замка» и по 2–4 биома на каждую главу, около 20 всего. Поэтому сетку я предлагаю использовать не как список новых биомов, а как референсы для уже задуманных.

## 2. Вопросы

1. **Сетка как референс.** Подтверди: сетка не добавляет новых биомов, а уходит референсами в уже задуманные. Или Штаб хочет что-то добавить: кровавый лес, отдельный кристальный лес в Р5, «жуткие пустоши» над глубокой тьмой?
2. **Кровавый лес.** Подойдёт ли он как «угасшая» версия какого-то леса? Например, часть Дола после главы 1 краснеет: красная листва и трава через цвет биома (перекрашиваются только дуб, тёмный дуб, джунгли, акация и мангр), стволы из `mangrove_log`, багровые споры.
3. **«Угасшие» биомы.** Документ говорит: после главы часть земель темнеет и меняется биом. Кто готовит пары «светлый → угасший» и контуры зон подмены: Архитектор в карточках или Штаб в отдельном списке?
4. **Реестр биомов.** Сейчас каждый биом описан в карточке своей локации, по 1–2 строки. Нужен ли сводный документ «Реестр биомов»: по одной записи на биом с точными цветами (hex), туманом, частицами, звуками, музыкой и контуром зоны? Это удобно для одной задачи Claude Code на все биомы сразу. Если да, я его составлю, по 3–4 биома за раз.
5. **Задача билдеру.** Задачи на биомы у Claude Code пока нет (T-001 – T-005 их не касаются). Когда её ставить: до первых построек или вместе с ними? От биома зависят цвет травы и листвы вокруг построек и спавн мобов.
6. **Спавн мобов в биомах.** Кто задаёт список мобов своего биома: Штаб, ведь мобы — его зона, или Архитектор предлагает в реестре?

## 3. Технические замечания для решения Штаба

Проверено по реестрам 26.3 в `docs/reference/`. Окончательно формат проверит Claude Code.

1. **Погода общая на весь мир.** Биом решает только, чем станет осадок: снегом, дождём или ничем. «Снег почти всегда» в Белой Тиши значит дождь почти всегда во всём мире. Варианты: (а) снег в Тиши — частицы биома, погода обычная; (б) датапак держит погоду включённой большую часть времени, остальные регионы терпят дождь. Предлагаю (а).
2. **В 26.3 у биомов есть атрибуты окружения** (`environment_attribute`). Среди них цвет блочного света (`block_light_tint`), дальность тумана (`fog_start_distance`, `fog_end_distance`), естественный спавн (`natural_mob_spawns`), правило кроватей (`bed_rule`), горят ли монстры (`monsters_burn`). Если их можно задавать для отдельного биома, отсюда следуют:
   - «мертвенно-синий свет» Тропы Мёртвых и «свет от огня душ» Города Мертвенного Света — честный цвет света, а не только шейдеры;
   - «плотный туман» — реальная дистанция тумана для отдельного биома;
   - бессонница: запрет сна в отдельных биомах без функций датапака;
   - безопасность Приюта через `natural_mob_spawns`.

   Какие атрибуты действуют на уровне биома, а какие только на измерение, нужно проверить первым шагом задачи на биомы.
3. **Ванильные биомы Незера в верхнем мире.** Если взять `basalt_deltas` за основу Пепельной Пустоши, вместе с пеплом придут гасты и магмовые кубы. Нужна своя копия биома со своим спавном.
