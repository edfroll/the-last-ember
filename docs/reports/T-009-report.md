# T-009 · Зал Пробуждения: народ, класс, черты, наборы — отчёт билдера

ДЛЯ ШТАБА · 22.10.2026 · модель Sonnet · статус: **выполнено**, проверено двумя реальными клиентами и замерами. Эдвард ничего не тестировал.

## Что сделано

- **Путь игрока** целиком работает: Келья → Зал Народов → Купель → площадь.
  - Новичок появляется на свободном ложе Кельи, точка возрождения там же. Через 5 секунд дверь Кельи открывается навсегда.
  - Площадки народов и алтари классов — `interaction`: первое нажатие даёт описание, второе в течение 10 секунд — выбор. Повторное нажатие после выбора: описание и строка «Твой выбор уже сделан».
  - После класса точка возрождения переходит на Главный Костёр. Дверь Зал → Купель открывается после первого выбранного народа, Купель → лестница после первого выбранного класса. Назад — свободно.
  - Без народа не пройти в Купель, без класса — в коридор к лестнице: игрока мягко отводит назад, без урона, над хотбаром «Сначала выбери народ / класс».
  - Камень народа на дне Купели загорается (`sea_lantern`), символ класса над чашей вспыхивает. Четыре огня у решётки загораются, когда класс есть у всех игроков на сервере.
  - Поздний игрок (после `char/reset`) проходит путь заново, остальные ему не мешают; огни и двери остаются как были.
- **Черты народов:** все значения по таблице задачи, проверены командой `attribute … get` по каждому атрибуту каждого народа (раздел «Как проверено»).
  - Второе дыхание людей (здоровье ниже 6 → регенерация II и сила I на 6 с, откат 3 минуты), «Герой деревни» постоянно.
  - Эльфы: стрелы +25% урона.
  - Гномы, полурослики (тег `le.race.halfling`), пеплорождённые (иссушение снимается, удушье втрое быстрее).
- **Классы:** рыцарь (Сопротивление I постоянно, скорость удара +20%, досягаемость +0,5), следопыт (стрелы летят вдвое дальше), ворожей и знахарь — только наборы.
- **Наборы** по таблице задачи, выдаются один раз (тег `le.kit`). Предметы `le_keep`: посох, рог, котёл знахаря, книга ворожея. Кираса и щит рыцаря сразу надеты.
- **Админ-функции:** `execute as <игрок> run function last_ember:char/reset` и `… char/set {race:1,class:1}`.
- **Генератор:** `tools/gen_char.py` строит таблицы и описания; остальное — `function/char/*.mcfunction`. Правила в `CLAUDE.md`.

## Что отличается от задачи и почему

1. **Следопыт: скорость стрелы ×1,5, а не ×2.** Задача говорит «летят в 2 раза дальше» и «скорость ×2» одновременно. Из-за сопротивления воздуха ×1,4 даёт ×1,78 по дальности, ×2 — около ×3,3. Взял ×1,5, итог ×1,97. Урон стрелы пропорционален скорости, поэтому базовый урон делится на тот же коэффициент: сила удара прежняя, меняется только дальность.
2. **Удушье пеплорождённых — эмуляция.** В 26.3 командами нельзя писать NBT игрока, в том числе запас воздуха (`Air`). Поэтому: запас воздуха читается, когда израсходовано 100 из 300 тиков (как при ×3), начинается урон `drown` по 2 каждые 10 тиков. Это минимальный промежуток из-за кадров неуязвимости, то есть вдвое чаще ванильных ударов. Итог ×2,6 к скорости гибели. Вариант «добавить урон в обработчике достижения» не годится по той же причине: второй удар в тот же момент игнорируется.
3. **«Герой деревни» без значка.** Команда `effect give` позволяет скрыть частицы, но не значок. Значок остаётся. Если мешает, уберу в ресурс-паке или заменю эффект цены другим способом.
4. **Рог следопыта** — обычный `goat_horn` без компонента `instrument`: молчит.
5. **Посох ворожея** — заглушка из палки с именем и описанием. Модель посохов — позже.
6. **Игрок сразу с `char/reset`/`char/set` для тестов; старые тесты T-004…T-007.** Новичок теперь сначала в Келье, поэтому они зависят от `scoreboard players set #autochar le.e 1` (новички без Зала, народ и класс 1, без тегов и набора, привязаны к костру `start`). Тесты зон требуют своих тестовых зон (`gen_zones.py zones/test_zones.txt`), как и раньше; я прогнал только то, что относится к T-009.
7. **Эффекты после смерти.** Модификаторы живут, а эффекты (`Герой деревни`, Сопротивление) возвращаются в течение секунды.

## Что может проверить только живой игрок

Короткое задание Эдварду, без сюжета: после `char/reset` пройти Зал за двух разных персонажей, например эльфа-рыцаря и гнома-знахаря, и сказать, ощущается ли разница в росте и скорости и не мешает ли что-то идти. Командой для подготовки: `execute as edfroll run function last_ember:char/reset`.
