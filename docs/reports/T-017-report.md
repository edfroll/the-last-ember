# T-017 · Торговцы — отчёт билдера

ДЛЯ ШТАБА · 22.10.2026 · модель Sonnet · статус: **выполнено**, проверено двумя реальными клиентами с **настоящими покупками через окно торговли** (в dev-агент клиента добавлены действия `!trade_sel N`, `!trade_take`). Эдвард ничего не тестировал.

## Что сделано

- **Механизм:** `traders/traders.txt` + `traders/items.txt` (заготовки) → `tools/gen_traders.py`. Житель (уровень 5) или странствующий торговец, `NoAI`, `Invulnerable`, `PersistenceRequired`, `Silent` (параметр), теги `le.npc`, `le.trader`, `le.noelite`, имя видно, лицом по `yaw`, параметры профессии, типа, `scale`. Вокруг каждого — зона `no_spawn` 16 блоков (генератор пишет `zones/traders.gen.txt`). Предупреждение в лог, если под торговцем нет твёрдого блока.
- **Сделки** из файла: до двух позиций в цене, `uses` = число покупок за всю игру, без пополнения; цена трофея — по `custom_data {le_trophy:"<регион>"}`, имя не важно; заготовки (книга чар, именной клинок). Цены стабильные (`priceMultiplier` 0, спрос 0), опыт за сделку ванильный.
- **Приветствие:** первое ПКМ каждого игрока — одна строка от имени торговца (тег игрока), окно торговли открывается как обычно.
- **Кузнец Приюта** — «Кузнец Хальвард» в (58, 101, 27), лицом на север, 8 сделок по таблице задачи. Настоящая покупка щита за 2 трофея Р1 проведена.
- Админ: `trader/reset {id}`, `trader/stock {id}`; тесты `tools/test_traders.py`.

## Что проверено

- Сделки через настоящее окно: трофей с любым именем платит, две позиции в цене, заготовка из `items.txt` (книга Защиты II, именной клинок), странствующий торговец; трофей другого региона не платит; израсходованная сделка не повторяется.
- Скидка «Героя деревни» (человек): цена первой сделки меньше на 1 (30% с минимумом 1); у эльфа цена из файла; спрос остаётся 0.
- Не умирает и не двигается: удар игрока (без урона и слухов), креопер рядом, зомби вокруг 8 с (нет превращения), толчок, посадка в лодку (снимается за секунду), телепорт (возвращается на место).
- **Нет пополнения за 3 игровых суток** рядом с лекторами (рабочий блок библиотекаря), `tick sprint 72000`: остатки те же, уровень 5, новых сделок нет.
- Нагрузка: 3 торговца 6,7 мс на tick.

## Отличия и находки

1. **Трофеи пришлось переименовать (затрагивает T-014).** Окно торговли берёт цену только из одного стака: трофеи с разными именами (по убитой элитке) не складываются в стак, и игрок с «Курганным мертвецом» ×1 и «Плакальщиком» ×1 не может заплатить 2 трофея (проверено настоящим окном). Раз цена сопоставляется по `custom_data` (это работает), я дал трофею региона одинаковые имя и описание — «Трофей Р<N>» («Трофей Незера»), строку об убитой элитке убрал (любое различие компонентов — в том числе описания — не даёт стака). Трофеи теперь складываются (проверено: три разные элитки — один стак).
2. Сделки уже стоящего торговца не обновляются при правке файла — нужен `trader/reset {id}` (для Кузнеца: один раз после обновления).
3. Окно торговли открывается и у игрока в режиме приключения (внутри зоны `no_spawn` 16 блоков вокруг торговца игроки по общему правилу зон — в приключении).
4. Dev-агент теперь закрывает контейнеры настоящим `closeContainer` (раньше окно закрывалось только на клиенте, предметы из окна торговли возвращались лишь при следующем открытии).
