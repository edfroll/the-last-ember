# ДЛЯ ШТАБА — отчёт T-019 · Сокровищницы и лут

29.10.2026 · ветка `claude/project-thread-4px3o0`

## Что сделано

- **Задача** `docs/tasks/T-019-treasuries-loot.md` (файла не было — написана по `economy.md`).
- **Генератор** `python3 tools/gen_loot.py [доп_файл]` → таблицы `loot_table/chests/r0..r6/common`, `loot_table/item/*` (классовые вещи, гримуар Починки, мутная склянка), `loot_table/vault/*` (по таблице на сокровищницу + `good_rN`, `filler_rN`), `advancement/vault/open_<id>`, `function/vault/gen/*`. Посохи как таблицы лута (`item/staff_<id>`) выпускает `tools/gen_seer.py`.
- **Обычные контейнеры:** 2–4 броска из пула региона; редкие позиции (слитки с Р2, книги I, слизь, лапка, мутные склянки) — с ванильным `quality`, поэтому удача человека (+1) их поднимает: по таблице Р2 редкое за бросок 14,8% → 25,0%.
- **Сокровищницы:** `treasury/vaults.txt` (сейчас пустой, места ставят задачи регионов; формат в комментарии: `danger`, `main=`, `clue=`/`hint=`, `block=`, `build=0`). Контейнер получает `LootTable "last_ember:vault/<id>"`, лут создаётся ваниллой при первом открытии (с удачей открывшего). Главный предмет выбирается в момент открытия условиями `int_value_check` по счётам раскладки (`#m.<id> le.vt`) — без подмены содержимого и без проверки взгляда.
- **Раскладка** (`vault/gen/layout`) при первом старте и при смене списка сокровищниц (версия-хэш): шаблон → Р6, Гнев → `danger` Р5/Р6, пары рыцаря и знахаря → Р2/Р4, следопыта → Р3/Р5 (кто куда — случайно), посохи — случайная перестановка по Р1–Р5; яблоко — одно на регион, Починка — одна в Р6; без главного — запасной (лучшая книга региона + слитки ×2). Открытые сокровищницы и взятые посохи при пересчёте не трогаются.
- **Стартовый посох** (`seer/give_random` → `vault/gen/staff_pick`): из ещё не взятых; его закрытая сокровищница получает запасной предмет. Открытие сокровищницы с посохом отмечает посох взятым.
- **Классовые вещи** (все `le_keep`): Щит Стража (отражение 50% — `knight/reflect_*`), Латы Последнего Дозора, Лук Дальнего Ветра, Колчан Теней, Котёл Старой Знахарки (+1 склянка — `potion/emit_n`, тег `le.pot_old`, снимается собой), Сумка Травницы.
- Админ: `vault/layout`, `vault/relayout`, `vault/refill {id}`, `vault/reset_staffs`.

## Как проверено

Сервер 26.3 на Mac Эдварда (облачное окружение у проекта не выбрано — см. ниже), `tools/test_vaults.py` на 22 тестовых сокровищницах (`treasury/test_vaults.txt`): **30/30 без клиента, 13/13 с ботом Cam**.

- 300 раскладок: каждый главный предмет ровно один раз и в своих регионах, Гнев только в `danger`, яблоко одно на регион, Починка одна, вторых главных нет. Посох × регион (Р1..Р5): все клетки 48–78 из 300.
- Пять ворожеев подряд — пять разных посохов, их сокровищницы → запасной; шестой — любой; взятый посох не раскладывается; настоящий набор ворожея отмечает посох.
- Содержимое каждой сокровищницы по раскладке, 3–5 хороших, в Р2 1–2 гримуара, в Р6 Починки нет вне раскладки; обычные контейнеры 2–4 вещи.
- Настоящее открытие ботом: главный предмет на месте, `#o` = 1, повторное открытие ничего не добавляет; открытие сокровищницы с посохом убирает посох из стартового пула.
- Удача: эльф 11 редких из 135 стаков, с удачей +100 — 78 из 87 (`quality` работает на наших таблицах).
- Щит Стража: удары 6/12/30/50 → 2/6/14/16 (×2), обычный щит — 25%.
- Старый котёл: 2–4 склянки на ступени 0 (обычный 1–3).
- Нагрузка: раскладка только при старте; в цикле — проверка «построить контейнер» раз в секунду. Тик тест-мира 12,4 мс — известный фон (хвост T-018), к T-019 не относится.

## Отличия от задачи

- «Карта к другой сокровищнице» — пока **обрывок карты** (бумага с текстом `hint` целевой сокровищницы), не ванильная карта: настоящей карте нужен `map_id` с данными. Если нужна рисованная карта — сделаем в задаче региона.
- Котёл Старой Знахарки ставится Shift+ПКМ как обычный; клик по очагу ботом не прогонялся (код тот же, что у обычного котла, +1 проверен напрямую).
- Если ящик опустошит воронка до игрока, ванилла заполнит его без удачи и без отметки «открыта». Сокровищницы должны стоять в неразрушимых зонах (T-004) — задачи регионов.
