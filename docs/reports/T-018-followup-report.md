# ДЛЯ ШТАБА · Малая правка T-018: фон нагрузки и `wound/venom`

29.10.2026 · проверено в облаке (сервер 26.3, RCON, без клиентов)

## 1. Фон нагрузки 14 мс

**Причина — проверка ключей глав (T-013), `altar/keys_loop` раз в 10 тиков.** Лаборатория ни при чём.

Для каждого из 18 ключей цикл дважды перебирал **все предметы на земле**, и один из двух переборов — селектором `@e[type=item,nbt={…}]`, который сериализует каждый предмет в NBT. Плюс одна общая макро-функция `key_watch_m` вызывалась с 18 разными аргументами, а ванилла кэширует только 8 наборов аргументов на функцию — каждый вызов заново разбирал текст. Стоимость растёт с числом предметов на земле. В тест-мире после тестов лаборатории (убитые мобы) и T-019 (лут через `loot spawn`) их сотни — отсюда пики раз в 10 тиков и среднее 12–14 мс. В T-008 (1,9 мс) замер шёл на чистой площади Приюта без предметов и без мобов (зона `no_spawn`).

**Исправление** (`tools/gen_altars.py`):
- один проход по новым предметам: тег `le.kchk`, а ключам (`ominous_trial_key`) — ещё `le.kitem`; проверки на земле смотрят только на `le.kitem`, `nbt=` больше нет;
- у каждого ключа своя макро-функция `altar/gen/kw_<id>` (id вписан, аргумент только `gen` — кэш попадает) и `gen/kh_<id>` без макро;
- `keys_join` (раз в секунду на игрока) зовёт `key_owed` только при `pend:1b`.

**Замеры** (облако, 289 чанков `forceload` у (808, 808), ~90 враждебных мобов, ночь, без игроков; среднее / P95, мс):

| Состояние | ~60 предметов на земле (дроп мобов) | 360 предметов на земле |
| --- | --- | --- |
| Только ванилла (датапак выключен) | 3,7 / 5,5 | 4,6 / 6,1 |
| Датапак до правки | 5,5 / 14,2 | 9,2 / 35 (P99 до 132) |
| Датапак после правки | 4,7 / 6,5 | 5,8 / 8,3 |

Профайлер (`perf`): `keys_loop` было 1,63% всего времени сервера (~8 мс за вызов), стало 0,18%. Весь датапак теперь ~0,85 мс на тик; остальное — ванильные мобы и чанки.

**Проверено:** ключ на земле запоминается (`it:1b`), копия старого поколения на земле удаляется, исчезновение ключа с земли даёт новое поколение и `pend`. **Не проверено без клиента:** ключ в инвентаре игрока (`kh_<id>`) — прогнать `python3 tools/test_altar.py keys` на Mac при следующем запуске клиентов.

Правило на будущее записано в `CLAUDE.md` (раздел «Нагрузка»): не звать одну макро-функцию в цикле с >8 разными аргументами, не использовать `nbt=` в циклах.

## 2. `wound/venom` — Яд

- Укус клешнями сколопендры (её собственная атака, достижение `lab/hit_cent`) → отравление I на 8 с; укус, пока яд держится, → отравление II на 8 с, дольше не растёт. Удар корпусом (`lab/cent/slam_hit`) яда не даёт (тег `le.noven` на время урона).
- Снимают молоко и противоядие знахаря (любое снятие отравления обнуляет счёт `le.wven`). Вода Исцеляющего озера появится с Р2: ей достаточно снимать отравление.
- Строка над хотбаром: «Яд — нужно противоядие или молоко».
- Проверено на сервере на корове (I → II → снятие → снова I). Случай в `tools/test_lab.py wounds` добавлен — для прогона с клиентами.
