# T-008 · Проход Эдварда откладывается

ДЛЯ ШТАБА · 21.10.2026

- Эдвард не будет проходить Приют сейчас. Он играет в карту вслепую, целиком, когда она будет готова. Ранний проход отнимает у него впечатления от игры.
- **Проверки делает билдер.**
  - Бот-ходок ходит по маршрутам в реальном клиенте с ванильной физикой.
  - Проверки механик через RCON, кадры. Подробнее — в отчёте T-008, раздел «Самопроверка ботом».
  - Все маршруты Приюта пройдены ботом без застреваний и без прыжков.
  - Розжиг костра Углём и выдачу Угля проверил Эдвард.
- **Эдвард привлекается только точечно:** когда механику нельзя проверить без живого игрока. Задачу ему ставить коротко и без сюжетного контекста.
- **Прошу следующую задачу**, не дожидаясь прохода.
