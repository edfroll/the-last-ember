# T-021 · Ворота регионов, границы и шорткаты — отчёт билдера

06.11.2026 · облачное окружение `last-ember-mc26`, мир с Приютом (сид 10845), клиенты Cam и Cam2.

## Что сделано

**Файл и генератор.** `gates/gates.txt` (формат в комментарии: строки `border`, `gate`, `shortcut`) → `python3 tools/gen_gates.py [доп_файл]` → `function/gate/gen/*` (64 функции), `zones/gates.gen.txt` (читает `gen_zones.py`), `gates/borders.gen.json` (для офлайн-инструмента), заглушки крючков `gate/hook/<id>` (пишутся, только если файла нет). Тестовый набор `gates/test_gates.txt` + `contracts/test_gate_contracts.txt`; в коммите всё перегенерировано без них.

**Границы** (`gates/gates.txt`, по «Границам регионов»): Западный хребет x −665 (z −620…650, проём z −195…−185), Дозорный z −620 (x −1500…−665, проём x −885…−875), Северная стена z −870 (проём x −563…−557), Разлом z 650 (проём x −2…2), Восточный хребет x 665 (z −870…650, без проёма), четыре края мира x/z ±1500. Ширина проёмов — предварительная (см. вопросы).
- Полосы приключения ±40 от оси — зоны с новым флагом `border` (`gen_zones.py`).
- **Барьер — офлайн** (`tools/borders.sh apply [id…]`, Java `tools/seedmap/Borders.java` на классах BlockWriter): в плоскости оси от y −64 до 319 каждый блок без полной коллизии (воздух, вода → `barrier[waterlogged=true]`, лава, растения, снег-слой, двери, плиты, ступени…) становится `barrier`, полные блоки остаются, блочные сущности на заменённых местах удаляются. Повтор безопасен (второй проход — 0 замен). Несгенерированные и **недогенерированные** чанки (статус не `full` — генератор потом прорежет в них пещеры) пропускаются и выводятся списком.
- Проверка — `python3 tools/borders_check.py holes [id…]` (каждый столбец оси вне проёма закрыт от −64 до 319) и `… walk x1 z1 x2 z2 точки…` (заливка по столбцам: точки по разные стороны стыка не связаны при заложенных проёмах; печатает и связность с открытыми проёмами).
- Выше мира: в полосе `border` выше y 300 игрок не пересекает ось вне проёма (`gate/gen/sky_<id>`, раз в 5 тиков возвращает на свою сторону), эндер-жемчуг выше y 316 в полосе исчезает. Иначе элитры и жемчуг уходят над барьером (у мира потолок 320).
- `gen_gates.py` падает с ошибкой, если костёр стоит ближе 7 блоков к оси вне проёма (барьер в зоне костра). Сейчас таких нет.

**Ворота глав.** `#gate_<id> le.gate` + storage `last_ember:gates g.<id>`, флаги `#open_r0`, `#open_r1` = 1 с `load`, `#open_r2…r6`, `#open_final`. Крючки `altar/hook/chapter_1…6` зовут `gate/gen/chapter_N` → `gate/gen/open_<id>`: гром всем, частицы и звук у точки `at=` игрокам в 64 блоках, строка над хотбаром всем (тексты — заглушки в файле), крючок `gate/hook/<id>`. Шаблоны `closed=/open=` ставятся `place template`, когда чанк загружен; не загружен — при загрузке (сверка раз в секунду, `#gatev_<id>`). Повтор `gate/open` ничего не меняет. Админ: `gate/open`, `gate/close` (тест), `gate/status`.

**Шорткаты.**
- Сторона Приюта — для всех шести регионов: клетки решётки, створок, фонарей, баннера и триггера считаются из модели `tools/build/gates.py` (те же, что строил T-008), смена `setblock`/`fill`. Закрыто: решётка, створки закрыты, темно, без баннера; ПКМ по решётке — «Заперто с той стороны». Открыто: решётки нет, створки открыты, 2 фонаря, баннер региона над аркой.
- Дверь в регионе: `python3 tools/build/shortcut_door.py` → `structure/shortcut/door_r1…r6.nbt` (портал 9×10 из акцентного блока региона, `dark_oak_door`, тамбур 7×7 высотой 5, цепи крест-накрест над аркой / 2 фонаря). Ставится датапаком по строке `shortcut … build=1`, когда чанк загружен. Открытие `near:<r>` или `click`; открытый шорткат открыт навсегда с обеих сторон (`#sc_rN = 1`). Зона приключения — цилиндр r 8 у двери. В `gates.txt` строки дверей закомментированы (координаты из карточек — для справки): рельефа регионов ещё нет.
- Перенос (на каждого игрока отдельно): триггер у глухой стены (коробка 5×3×3) → спешивание, тьма и слепота, шаги и ветер; через 1 с `tp` в середину тамбура той стороны лицом к выходу, слепота 1 с спадает; вышел из зоны раньше — отмена; перезарядка 3,25 с, точка выхода вне триггера. Приручённые волки, кошки, попугаи игрока в 12 блоках, которые не сидят, едут следом; лошадь остаётся. Носитель Угля остаётся носителем, свет Угля переезжает. Наблюдатель и креатив — без тьмы.

**Доска заказов.** Заказ региона N появляется при `#open_rN = 1`; `open=` в строке заказа — дополнительный порог по `#chapters`, только если указан (`gen_contracts.py`).

## Что отличается от задачи и почему

- Барьер — до y 319 (это последний блок мира; y 320 не существует).
- Добавлена защита выше мира (y ≥ 300, жемчуг выше 316): без неё через ось можно перелететь на элитрах или перекинуть жемчуг над потолком мира.
- Листва считается твёрдой (полная коллизия) и остаётся — в приключении её не сломать.
- Недогенерированные чанки пропускаются (как несгенерированные): если записать в них барьер, генератор потом прорежет пещеры поверх.
- У косых ворот Приюта (r1 45°, r4 160°, r5 215°) триггер — круг r 2,5 у глухой стены, а не коробка: коробка по диагонали задевала бы проход тамбура.
- Перезарядка переноса 3,25 с (65 тиков) — чуть больше 3 с, чтобы гарантированно перекрыть тьму.
- `gate` без `at=` у Рамки Предков и вершины Пепельной горы (точек ещё нет) — только флаг и крючок. У колодца `at=40,101,−44` (точка `well_swap` из T-008).
- Случай «регион закрыт — заказа нет на доске» проверяется в `test_gates.py board` (свой тестовый заказ Р2), а не в `test_contracts.py`: там все заказы Р1, а Р1 открыт всегда.
- Индекс зон вырос с 64 до 996 ячеек (полосы краёв мира длиной 3000 блоков), 424 КБ функций; проверка игрока по-прежнему смотрит только свою ячейку.
- Камни, полы и узоры баннеров дверей по регионам — мой выбор по знакам из карточек (`REG` в `shortcut_door.py`, `BANNERS` в `gen_gates.py`); поправить легко.
