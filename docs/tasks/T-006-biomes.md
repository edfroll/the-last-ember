# T-006 · Свои биомы и заливка

Штаб → билдер · 20.10.2026 · модель: Sonnet · после T-005

## Цель

Свои биомы из реестра становятся настоящими биомами датапака и заливаются в мир по контурам. Сначала Р0 и Р1, дальше реестр будет расти.

## Входные данные

`docs/design/biomes/registry.md` и ответ Штаба рядом с ним (`Ответ Штаба на реестр, Р0 и Р1.md`). Реестр — источник правды: цвета, туман, частицы, звуки, слоты музыки, осадки, атрибуты окружения, спавн, контуры, переходы, «угасшие» версии.

## Что сделать

1. **Первый шаг — проверка атрибутов окружения 26.3.** Какие из `fog_start_distance`/`fog_end_distance`, `block_light_tint`, `bed_rule`, `natural_mob_spawns`, `monsters_burn` и других задаются на уровне биома, а какие только на измерение. Короткий отчёт сразу, до остальной работы: от него зависит реестр.
2. **Генератор биомов.** Реестр → JSON биомов в `datapack/data/last_ember/worldgen/biome/`. Руками JSON не править, как в T-001. Слоты музыки пока ссылаются на заглушки ресурс-пака.
3. **Заливка.** Инструмент `fillbiome` по контурам в порядке из реестра: основа, биомы локаций, ванильные биомы. Переходы — смешанная полоса заданной ширины (а не ровная граница по сетке 4), чтобы цвет травы и тумана менялся плавно.
4. **«Угасшие» версии.** Функция датапака, которая по событию главы перезаливает контур «угасшим» биомом. Учти: игрокам нужно перезайти в чанк или игра должна переслать его, чтобы увидеть новый цвет. Проверь, как это работает в 26.3, и сделай так, чтобы смена была видна сразу.
5. **Спавн** по реестру. Криперы в Доле редкие.

## Критерии готовности

- Все биомы Р0 и Р1 залиты на тестовом мире.
- Автоскриншоты: по одному кадру в каждом биоме днём и ночью, плюс два кадра на переходе Приют → Дол и Дол → Курганы.
- «Угасшие» версии Р1 включаются функцией, смена видна без перезахода.
- Спавн: за 10 игровых минут в Приюте и Грибной роще — ноль монстров, в Доле — только разрешённые.
- Отчёт по атрибутам окружения — отдельным разделом.

## Связи

Рамочный документ: «Свои биомы» в технических рамках. Карточки локаций: поле «Свой биом».
