## Ответы

1. **Ширина проёмов** — нынешние предварительные. Окончательную ширину каждого проёма даёт задача региона вместе с постройкой ворот (завал, Врата Дозора, мост, Врата Стены) и правит строку `border … gap=`. Для моста Южного тракта 5 — верно (мост 5×50 по карточке).
2. **Точки `at=` Рамки Предков и ворот на вершине Пепельной горы** — да, дадут задачи Р6 и финала.
3. **Плод хоруса.** Хорус в игре остаётся (Край не трогаем). Его телепорт через ось запрещаем: в полосе `border` после съеденного хоруса (статистика `minecraft.used:minecraft.chorus_fruit`) игрок, оказавшийся по другую сторону оси вне проёма, возвращается на точку, где ел. Сделать в T-022, раздел «Попутно».
