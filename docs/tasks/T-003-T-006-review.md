## T-005 · Костры и Уголь

1. **«Угас» (state 2)** — оставь под задачу угасания мира.
2. **Радиус 16 сферой** — да.
3. **Котёл на костре.** Знахарь с котлом в руке: Shift+ПКМ по горящему очагу — датапак ставит котёл над огнём (над очагом по стандарту 3 блока воздуха).
