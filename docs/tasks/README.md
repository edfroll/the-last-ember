# Задачи и отчёты

Штаб и билдер общаются через репозиторий. Edward только пингует: «новая задача» или «есть отчёт».

## Задачи — `docs/tasks/`

Штаб пишет по файлу на задачу: `T-NNN-короткое-имя.md`. Задачи приходят через PR Штаба в `main`.

Формат задачи: цель; механика; критерии готовности; как проверить в игре; связи; модель (Sonnet по умолчанию, Opus — где помечено).

## Отчёты — `docs/reports/`

Билдер пишет по файлу на задачу: `T-NNN-report.md`, коммитит сам.

Формат отчёта: что сделано (коммиты); как проверено; что отличается от задачи и почему; что может проверить только живой игрок; вопросы к Штабу.

Edward не читает сюжетные подробности, поэтому в чат ему — только коротко и без спойлеров: что готово и что нужно от него.

## Порядок

1. Перед началом работы билдер делает `git pull` в `main`.
2. Берёт задачи по номеру, если Штаб не указал другой порядок.
3. Отчёт по задаче — до перехода к следующей, если задачи связаны.
