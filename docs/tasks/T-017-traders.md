# T-017 · Торговцы

Штаб → билдер · 22.10.2026 · модель: Sonnet

## Ответы по T-016

T-016 принят. Отличия приняты. Правило про лавовые желоба (на уровне пола или за стенкой) передам в задачи регионов. Тип `puzzle` — позже, с загадками регионов. `respawn` статуй без своей логики — нормально.

## Цель

Общий механизм торговцев: неподвижный неуязвимый житель со сделками из файла, со своей валютой, без пополнения сделок. Первым ставим **Кузнеца Приюта**, остальных — задачи регионов по этому же файлу. Экономика, валюты и цены — `docs/design/economy.md` (новый документ Штаба, прочитай целиком).

## Торговец

- Житель (или странствующий торговец — параметр) с `NoAI`, `Invulnerable`, `PersistenceRequired`, `Silent` (параметр — у шумных мест можно оставить звук), теги `le.npc`, `le.trader`, `le.noelite`. Имя видно. Лицом в заданную сторону. Профессия и тип жителя — параметры (внешний вид; свои текстуры — позже, ресурс-паком).
- **Сделки не пополняются.** `maxUses` в каждой сделке — сколько можно купить за всю игру. Проверь, что за 3 игровых суток рядом с рабочим блоком ничего не пополнилось (без ИИ житель не работает — но проверить надо).
- **Цены стабильные:** спрос (`demand`) не растёт, ударить торговца нельзя, слухи (`gossips`) не портят цены. Единственная скидка — «Герой деревни» у людей (T-009): проверь, что она работает и какая получается.
- Опыт торговли игроку — да (ванильный, по сделке), уровень жителя не растёт.
- Зомби не превращают торговца: вокруг торговца зона `no_spawn` радиусом 16 (флаг в описании торговца, генератор добавляет зону сам).
- Нельзя увести, толкнуть, посадить в лодку/вагонетку; падение в пустоту/лаву исключено местом (точка проверяется при постройке, предупреждение в лог, если под ним не твёрдый блок).
- **Приветствие:** первое ПКМ игрока по торговцу — одна строка в чат от его имени (текст из файла), окно торговли открывается как обычно. Каждому игроку — один раз.

## Файл

`traders/traders.txt`, генератор — как у остальных систем:

```
trader <id> <измерение> <x> <y> <z> <yaw> type=<villager|wandering_trader> prof=<профессия> vtype=<plains|snow|desert|…> name="<имя>" hello="<строка>" [silent=0] [scale=0.8]
  buy <предмет> <кол-во> [+ <предмет> <кол-во>] -> <предмет> <кол-во> uses=<N>
```

- Предмет — id или ссылка на заготовку из `traders/items.txt` (`<имя_заготовки> <id> <компоненты SNBT>`: книги чар, именные вещи, карты).
- **Трофеи** в цене сопоставляются только по `custom_data {le_trophy:"<регион>"}`, а не по имени (у трофеев разные имена по убитой элитке). Проверь, что ванильная сделка в 26.3 так умеет (частичное совпадение компонентов в цене); если нет — дай трофеям общее имя по региону, а имя элитки — строкой описания, и сообщи.
- Чужая валюта (мёд, тыквы, лёд, саженцы…) — обычные предметы, в цене одна из позиций сделки.

## Тестовый торговец

`traders/test_traders.txt` (перед коммитом перегенерировать без него): торговец со сделками всех видов — трофей в цене, две позиции в цене, заготовка из `items.txt` (книга чар, именная вещь), странствующий торговец вместо жителя, `scale` 0,8.

## Админ и тесты

- `trader/reset {id:…}` — вернуть сделки к началу (для тестов), `trader/stock {id:…}` — вывести остатки.
- Проверки: сделки по таблице; трофей с любым именем принимается; `uses` кончаются и не возвращаются через 3 игровых суток; цена не растёт после покупок и после удара; скидка человека; приветствие один раз на игрока; торговец не двигается, не умирает (урон, лава рядом, взрыв крипера рядом, зомби), не превращается; два игрока торгуют одновременно (общий остаток сделки); нагрузка.
