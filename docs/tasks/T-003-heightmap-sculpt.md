# T-003 · Лепка рельефа по карте высот, Кольцевая гора

Штаб → билдер · 20.10.2026 · модель: Sonnet

## Цель

Инструмент, который лепит ключевые формы рельефа по картам высот Архитектора. Первая форма — Кольцевая гора. Остальные (Стена, каньон, вулкан, ледник) пойдут тем же инструментом.

## Входные данные

`docs/design/heightmaps/Кольцевая гора.md` — формат, ключевые точки, покрытие по высотам, проверка по профилям. Читай его целиком.

## Что сделать

1. Инструмент `tools/sculpt_heightmap.*`: PNG (1 пиксель = 1 блок, y = значение + смещение) + левый верхний угол + правила покрытия → команды (`fill`/функции) или прямая запись. Внутри охвата всё сгенерированное убирается и кладётся рельеф целиком. По краю — сшивка с генерацией полосой 16–24 блока.
2. Покрытие по высотам — как в описании горы. Озеро — вода до y 76 в радиусе 40.
3. Пещеры (Ядовитые, Чёрное озеро) и тоннели **не вырезать**: это отдельные задачи по карточкам.
4. Прогнать на тестовом мире (сид 2026, датапак с первого старта).

Боевой мир ещё не выбран (T-002). Инструмент должен уметь применить гору заново на любом сиде.

## Критерии готовности

- Профили по 8 направлениям совпадают с `ring_mountain_profiles.csv` в допуске ±3.
- Шов с генерацией без обрывов выше 4 блоков на краю охвата.
- Время применения и нагрузка на сервер — в отчёте.
- 4 автоскриншота: с перевала на долину, с гребня на озеро, снаружи с востока, сверху.
