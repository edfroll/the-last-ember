# T-008 · Приют (Р0): первая постройка

Штаб → билдер · 21.10.2026 · модель: Opus · после T-007

## Цель

Построить хаб целиком по карточкам Архитектора на тестовом мире сида 10845. Это первая локация, на которой Эдвард сможет походить сам: всё, что он увидит в Приюте, — без сюжетных спойлеров.

## Входные данные

- `docs/design/locations/Карточки локаций Р0, партия 1.md` — Смотровая башня, Зал Пробуждения, **стандарт костра** (сквозной объект), **Урна Утраченного**.
- `docs/design/locations/Карточки локаций Р0, партия 2.md` — Главная площадь, Кузница, таверна с Доской заказов, Ворота шорткатов, Запечатанный колодец.
- Ответы Штаба на обе партии рядом с ними. Высоты: площадь на y 103 (сдвиг +13 уже внесён).
- Биом Приюта и переход — из T-006.

## Что сделать

1. **Стандарт костра и Урна.** Заменить заглушку `bonfire/build_here` постройкой по карточке, с вариантами по регионам (палитры в карточке). Урна — по карточке, с местом для имён на плите (T-007).
2. **Приют.** Площадь, Главный Костёр, Урна, Смотровая башня, Зал Пробуждения (с Купелью и четырьмя чашами классов, пятью статуями народов), Кузница, таверна с доской и погребом-тайником, шесть Ворот шорткатов (закрытые), Запечатанный колодец (состояние «до»). Шаблоны и скрипты — как удобнее; собранные куски сохраняй как `.nbt`, чтобы потом переставлять.
3. **Зоны** — весь Приют неразрушим (зона из карточки, с фундаментом).
4. **Без механик сюжета:** выбор народа и класса, жители, доска заказов, двери шорткатов, колокол — это отдельные задачи. Сейчас только постройки, свет и точки-маркеры для будущих механик.

## Критерии готовности

- Автоскриншоты: площадь днём и ночью, каждая постройка снаружи, Зал Пробуждения внутри, вид с башни.
- Нагрузка: время тика и FPS клиента на площади.
- Список того, что в карточках неоднозначно или не построилось как описано, — для Архитектора.
