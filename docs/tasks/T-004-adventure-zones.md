# T-004 · Неразрушимые зоны (режим приключения)

Штаб → билдер · 20.10.2026 · модель: Opus (основа для всего строительства)

## Цель

Система зон, внутри которых игрок не может ломать и ставить блоки. Это основа всех построек: Приют, подземелья, алтари, костры.

## Механика

- Зона — прямоугольник (x1, z1, x2, z2, y1, y2) или цилиндр (центр, радиус, y1, y2). Зоны задаются в одном файле данных; добавлять зоны должно быть просто (одна строка на зону).
- Игрок в любой зоне — режим приключения, вне всех зон — выживание. Зоны могут перекрываться и вкладываться.
- Исключения внутри зон через компоненты предметов `can_break` / `can_place_on`:
  - Лопата смотрителя ломает только `soul_soil` (Р1, кладбище);
  - котёл знахаря ставится на `campfire` и снимается обратно — в зонах костров, Приюта и везде, где есть огонь для котла.
  Сами предметы сделаем позже; сейчас — механизм и тестовые предметы.
- **Блоки в зонах должны быть защищены не только от игроков:** взрывы (криперы, ТНТ, огненные шары гастов), распространение огня, эндермены, падение блоков, если его вызывает игрок. Предложи и сделай решение для каждого источника. Ванильные правила игры (gamerule) можно менять глобально только с обоснованием: какие игровые механики это заденет вне зон.
- Флаги зоны (на будущее, сейчас — механизм и один флаг для теста): «Посох Мгновения не работает», «огонь посохов не ставится», «спавн монстров выключен».
- Производительность: проверка позиции раз в 5–10 тиков, без перебора всех зон на каждого игрока в каждом тике, если зон станет 200+.

## Критерии готовности

- Тестовый набор зон: прямоугольник, цилиндр, две перекрытые зоны, вложенная.
- 2 игрока (или игрок + бот/фейк через `execute as`, если иначе нельзя): переходы на границах, перекрытие, смерть внутри зоны и возрождение снаружи, вход по воздуху (падение, элитры, эндер-жемчуг).
- Крипер и ТНТ у стены зоны не ломают блоки зоны; огонь не распространяется в зону.
- Тестовые инструменты с `can_break` и `can_place_on` работают.
- Нагрузка: время тика при 200 тестовых зонах и 3 игроках.

## Связи

Рамочный документ: «Неразрушимые зоны» в технических рамках. Все карточки Архитектора указывают зоны в разделе «Пути».
