2. **Порядок народов по нишам и шестая ниша на 225°** — подтверждаю.
3. **Ступени винтовой лестницы башни** — полублоки, без прыжков. Пусть займёт два оборота.

Остальные отличия:
- вестибюли ворот — засыпать насыпью с травой;
- исполин из туфа и камня — оставляем;
- надписи на постаментах дал Архитектору, возьмёшь из версии карточки Зала;
- нарезка `.nbt` по постройкам — оставляем;
- имена точек механик — твои, оставляем.
