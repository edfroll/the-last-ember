# T-014 · Элитные мобы

Штаб → билдер · 22.10.2026 · модель: Sonnet

## Ответы по T-013

T-013 принят.

1. **Тепло** — тег `le.warm` достаточно. Ванильную заморозку в рыхлом снегу свойство не снимает — так и оставим: от рыхлого снега спасают кожаные ботинки, этому Р3 и учит.
2. **Зов — на Shift + F.** Щит рыцаря важнее: Уголь не должен перехватывать ПКМ. Убрать `consumable` с Угля. Зов: носитель присел и нажал F (смена рук), Уголь был в основной руке и оказался во второй → датапак возвращает его в основную руку (и то, что было во второй, — обратно во вторую) и колдует Зов. Без приседа F работает как обычно. Откат 60 с прежний. Свет (свойство I) при этом работает с Углём в любой руке.
3. **Ключ в хоппере = потеря** — допустимо: копия у последнего держателя, старая недействительна.
4–5 — приняты.

## Цель

Датапак замечает новых мобов и с небольшим шансом делает элитку: крупнее, сильнее, со своим именем и видом, с наградой получше. Шанс зависит от места (поверхность, пещера, подземелье), региона и того, угас ли регион. Элиток мало — каждая встреча заметна.

## Кто может стать элиткой

Зомби, кадавр, утопленник, зомби-житель, скелет, зимогор, болотник, иссохший скелет-иссушитель (`wither_skeleton`), паук, пещерный паук, ведьма, эндермен, ифрит, лавовый куб (только большой), слизень (только большой), пиглин-громила, зомби-пиглин, фантом.

**Не бывают:** крипер, гаст, хранитель, страж и древний страж, вихрь, скрипун, иссушитель, дракон, разбойники (у банд своя задача), чешуйница. Не трогать мобов с тегами `le.boss`, `le.giant`, `le.npc`, `le.noelite` (наши события и спавнеры), `le.elite` (уже элитка), мобов из ванильных спавнеров испытаний (`trial_spawner`).

## Шанс

Бросок один раз на моба, при первом обнаружении (в том же проходе, что `mob_eq/scan`), тег «брошено».

| Место | Базовый шанс |
| --- | --- |
| Поверхность (небесный свет есть) | 2% |
| Пещера, подземелье без неба (небесный свет 0) | 6% |
| Зона с флагом `dungeon` (подземелья, крепости, логова — флаг добавят задачи регионов) | 10% |

- **Угасание:** в регионе, глава которого пройдена, шанс ×1,5.
- **Ночь** на поверхности: ×1,25.
- Потолок: 20%.
- **Лимит:** не больше 2 живых элиток в радиусе 48 вокруг каждого игрока и не больше 8 на весь мир. Если лимит занят — моб остаётся обычным (бросок не повторяется).
- Регион — по карте регионов (`death/regions.txt`), отдельный файл не нужен.

## Какой становится

| Черта | Значение |
| --- | --- |
| Размер `scale` | ×1,3 (у пауков ×1,2, у фантома ×1,5) |
| Здоровье | ×2,5 (после — полное) |
| Урон | ×1,5 |
| Скорость | ×1,1 |
| Устойчивость к отбрасыванию | +0,3 |
| Броня | +4 |

- **Имя** видно над головой всегда (`CustomNameVisible`), цвет — тусклый красный. Имена — по региону и виду моба, файл `mobs/elite_names.txt` (`регион моб имя`). Для Р1 ниже, для других регионов — пока «<ванильное имя> — элита», заменим в задачах регионов.
- **Вид:** снаряжение-заглушка своего цвета на голове (кожаный шлем, окрашенный по региону), с `drop_chance 0`. Настоящие текстуры элиток — позже, вместе с ресурс-паком мобов. Редкие частицы вокруг (раз в 2 с, только если рядом игрок в 24 блоках).
- **Звук** при появлении в поле игрока не нужен — встреча должна быть внезапной.
- Тег `le.elite` (по нему уже пропускает `mob_eq`), счётчик региона.

## Награда

- Опыт ×3.
- Ванильный лут моба — как обычно (с вычисткой T-001).
- Плюс одна выдача из таблицы `last_ember:elite/<регион>`. Сейчас в ней — **Трофей** региона: предмет `custom_data {le_trophy:"r1"}`, имя «Трофей: <имя элитки>» (по убитому), `item_model` — заглушка, стакается до 16. Трофеи станут валютой у торговцев (задача экономики). Плюс с шансом 25% — одна случайная полезная мелочь из короткого списка (склянка, 4 стрелы, хлеб, кость) — потом заменим на пул экономики.
- Награда только если убил игрок (или его прирученный зверь, или снаряд игрока).

## Админ и тесты

- `function last_ember:elite/make` (на сущности: сделать элиткой без броска), `elite/stats` (сколько живых по регионам), `#elitechance` — множитель для тестов.
- Тест-скрипт: прогон N появлений мобов в каждом типе места (поверхность день/ночь, пещера, зона `dungeon`, угасший регион) — доля элиток в пределах ±50% от расчётной; лимиты 2 на игрока и 8 на мир; исключения (крипер, моб с `le.noelite`, моб испытания); награда только за убийство игроком; трофей с правильным именем; нагрузка tick с 30 мобами рядом.
