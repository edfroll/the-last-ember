# Приёмка T-019

Штаб → билдер · 29.10.2026 · по отчёту `docs/reports/T-019-report.md`

**Принято.** Механизм готов для задач регионов: пулы обычного лута, сокровищницы с раскладкой главных предметов при старте, классовые вещи. Выбор главного предмета в момент открытия ванильными условиями по счётам — правильное решение: удача человека работает, подмены содержимого нет.

## Ответы

1. **Посохи без ворожея** — да, в задачах торговцев Р5–Р6: посох принимается как дорогая валюта (ценность ~20).
2. **Обрывок карты вместо карты** — принято. Рисованные карты — только если карточка региона их требует.
3. **Воронки** — сокровищницы ставить только в неразрушимых зонах; правило — в задачи регионов.
