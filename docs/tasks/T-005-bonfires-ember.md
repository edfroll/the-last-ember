# T-005 · Костры-чекпоинты и Уголь (основа)

Штаб → билдер · 20.10.2026 · модель: Opus · после T-004

## Цель

Работающие костры и Уголь. Без смерти и пепельного следа (это T-006), без угасания мира (позже).

## Механика

**Уголь.** Уникальный ключевой предмет: свой вид (ресурс-пак: тлеющий уголь с мерцанием), имя «Последний Уголь», описание. Метка, по которой датапак его узнаёт и которую нельзя подделать в выживании. Ровно один Уголь на мир. Носитель — тот, у кого Уголь в инвентаре. Уголь нельзя выбросить, положить в сундук, рамку, воронку, отдать мобу. Передача — только через стелу костра (ниже).

**Костёр.** Реестр костров: id, координаты очага и точки возрождения 3×3, регион, тип (главный / обычный), состояние (не зажжён / горит / угас). Очаг — `campfire`, под ним сено (сигнальный дым) у горящего, без огня у незажжённого.
- **Зажечь** может только носитель Угля: ПКМ по очагу. Звук, частицы, столб дыма. Всем игрокам в радиусе 16 точка возрождения переносится к этому костру.
- **Отдохнуть у горящего костра** может любой игрок: ПКМ по очагу — его точка возрождения переносится сюда.
- **Возрождение** — только у костров. Обычные кровати точку возрождения не меняют. Соломенные кровати 26.3 пропускают ночь, не меняя точку, — проверь, что это так и с нашим механизмом.
- **Первый вход.** Пока ни один костёр не зажжён, точка возрождения — Главный Костёр Приюта. Он горит с начала игры и не гаснет.
- Главный костёр региона не гаснет никогда (флаг в реестре).
- **Стела с гнездом** у костра: носитель кладёт Уголь в гнездо (ПКМ по стеле с Углём в руке), любой игрок у этого костра забирает его (ПКМ по стеле). Пока Уголь в гнезде, над стелой видно, что он там.
- Костры — зоны приключения радиусом 6 (T-004).

**Инструменты для строительства:** функция «поставить костёр» по координатам и типу, которая сама ставит блоки очага и стелы и добавляет запись в реестр. Позже по ней расставим все ~45 костров.

## Критерии готовности

- 3 тестовых костра: главный и два обычных.
- Зажигание только носителем; другой игрок зажечь не может (сообщение-подсказка).
- Возрождение у последнего костра, на котором игрок зажёг или отдохнул; кровать не сбивает.
- Передача Угля через стелу между двумя игроками. Попытки выбросить Уголь (Q, смерть пока пропускаем, сундук, рамка, воронка, стойка) не проходят.
- Перезапуск сервера: состояние костров и точки возрождения сохраняются.
