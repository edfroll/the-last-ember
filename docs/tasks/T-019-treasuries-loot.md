# T-019 · Сокровищницы и лут

Штаб → билдер · 29.10.2026

## Цель

Общий механизм лута, которым будут пользоваться задачи регионов: обычные контейнеры с пулами регионов, сокровищницы с главным предметом, случайная раскладка главных предметов при старте игры, классовые вещи. Основа — `docs/design/economy.md` (разделы «Лут: бюджеты», «Кривая силы»). Мест в мире ещё нет (их ставят задачи регионов по карточкам), поэтому здесь — файлы, генератор, таблицы и тестовая площадка.

## 1. Обычные контейнеры

- Таблицы `last_ember:chests/r<N>/common` для `r0`…`r6` (Незер = `r6`). Сундук, бочка, горшок получают их через ванильный `LootTable` (BlockWriter или `data merge`), лут создаётся при первом открытии и общий на отряд.
- В контейнере 2–4 предмета из пула региона: еда, стрелы, факелы, кости, нитки, кожа, мутные склянки (T-010), ингредиенты знахаря; с Р2 редко 1–3 железных слитка; ещё реже книга чар I (зачарования — по кривой силы региона).
- **Удача людей.** Редкие позиции — с ванильным `quality`: у человека (удача +1, T-009) шанс на них выше. Проверить замером.
- Чужая валюта торговцев в пулах не лежит (кроме мёда в Доле — он оттуда родом).

## 2. Сокровищницы

Файл `treasury/vaults.txt` (формат — в комментарии файла): строка на сокровищницу — `id`, регион, измерение, точка контейнера, блок (сундук/бочка с направлением), флаги: `danger` (самая опасная в регионе), `main=<id>` (главный предмет задан задачей региона, в раскладку не входит), `clue=<id>` (внутри обрывок карты к другой сокровищнице) и `hint="…"` (что написано на обрывке, ведущем сюда).

Содержимое при первом открытии:

- **главный предмет** — по раскладке;
- 3–5 хороших: книга чар II–III (по региону), 4–8 слитков, зелья; **с Р2 из них 1–2 — гримуары** (зачарования — таблица «Гримуары» в economy.md, кроме Починки);
- сверх того, если выпало по раскладке: **золотое яблоко** (ровно одно на регион), **гримуар Починки** (один на игру, Р6);
- обрывок карты, если у сокровищницы есть `clue`.

**Раскладка при старте** (при первой загрузке датапака в мире, случайно):

| Главный предмет | Куда |
| --- | --- |
| Шаблон незеритового улучшения (1, второй — в бастионе по задаче Р6) | Р6 |
| Гнев Мёртвого Неба | сокровищница с `danger` в Р5 или Р6 (если таких нет — любая Р5/Р6) |
| «Щит Стража», «Латы Последнего Дозора» | Р2 и Р4, по одному, кто куда — случайно |
| «Котёл Старой Знахарки», «Сумка Травницы» | Р2 и Р4, по одному |
| «Лук Дальнего Ветра», «Колчан Теней» | Р3 и Р5, по одному |
| пять посохов | Р1…Р5, по одному на регион |

В регионе главный предмет кладётся в случайную сокровищницу без главного предмета. Сокровищницы, которым ничего не досталось, получают **запасной главный предмет**: книга чар высшего уровня региона и вдвое больше слитков. Если сокровищниц не хватает, главный предмет ложится вторым в случайную сокровищницу региона, генератор предупреждает.

**Посох ворожея на старте:** стартовый посох выбирается из тех, что ещё не взяты (не выданы другому ворожею и не вынуты из сокровищницы); его сокровищница, если ещё не открыта, получает запасной главный предмет. Второй ворожей в отряде получает другой посох. Если ворожея нет, посохи лежат в сокровищницах как есть (продажа их торговцам Р5–Р6 — в задачах торговцев).

Раскладка не меняется от перезагрузки. Если задача региона добавит сокровищницы в уже идущий мир, раскладка пересчитывается только для неоткрытых сокровищниц; вынутые предметы второй раз не появляются.

## 3. Классовые вещи

Все — с `le_keep` (не теряются при смерти), со своими именами и описанием.

- **Щит Стража** — щит, Прочность III. Рыцарь, блокируя им удар, отражает **50%** урона вместо 25% (T-010).
- **Латы Последнего Дозора** — железный нагрудник, броня 8, твёрдость 1, сопротивление отбрасыванию 0,1 (как алмазный, но на железной основе: ремонт слитками, благословение рыцаря чинит).
- **Лук Дальнего Ветра** — лук, Сила III, Бесконечность.
- **Колчан Теней** — 16 стрел иссушения (иссушение II, 5 с при попадании).
- **Котёл Старой Знахарки** — котёл знахаря (T-007/T-010), но варка даёт на 1 склянку больше. Ставится и снимается как обычный котёл, остаётся собой.
- **Сумка Травницы** — мешок с редкими ингредиентами котла: кроличья лапка, светящиеся ягоды, мёд, слизь, паучьи глаза, паутина.

Посохи и гримуары — готовые (T-011), в таблицы лута их выносит генератор.

## 4. Админ и тесты

- `vault/layout` — показать раскладку; `vault/relayout` — пересчитать (для тестов); `vault/refill {id}` — заново заполнить контейнер и снять отметку «открыта».
- Тестовые сокровищницы `treasury/test_vaults.txt` (3–4 на регион на площадке; перед коммитом перегенерировать без них).
- Проверки: правила раскладки на сотнях пересчётов (каждый главный предмет ровно один раз, в своих регионах, Гнев — в `danger`, яблоко — одно на регион, Починка — одна); стартовый посох убирается из своей сокровищницы, два ворожея — разные посохи; содержимое по числам; открытие игроком отмечается, повторно не заполняется; удача человека в обычных сундуках; Щит Стража отражает 50%; Старый котёл даёт +1; нагрузка (раскладка — только при старте, в тике ничего нового).

## Не в этой задаче

- Сами места, хозяева сокровищниц и путь к ним — задачи регионов по карточкам.
- Проклятый лут могил (Р1, Кладбище Павших Рыцарей) — в задаче региона.
- Лут боссов — в задачах боссов, из пула сокровищниц региона.
- Хвост T-018 (`wound/venom`, фон нагрузки) — отдельной малой правкой.
